# Flowly

Responsive landing page for an AI project-planning product, recreated from the desktop and mobile Figma frames. Built with React, Vite, and StyleX; Tailwind is not used.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

The local Figma assets are in `src/assets/figma`. Component styles and responsive rules live in `src/App.jsx` as StyleX styles; `src/index.css` contains the global reset and font imports.
